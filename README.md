# Tarragona guide — как устроен сайт

Сайт на 4 языках: **русский (RU)**, **украинский (UA)**, **английский (EN)**, **испанский (ES)**.
Адрес: https://tarragonaguide.tinuriel.workers.dev — при заходе на главную посетитель
попадает на свой язык (по настройкам браузера или по последнему выбору).

## Как устроен один пост

Каждое место — отдельная папка. В ней по одному файлу на язык и фотографии:

```
content/sights/cathedral/
  index.ru.md    ← русский
  index.uk.md    ← украинский
  index.en.md    ← английский
  index.es.md    ← испанский
  cathedral-1.jpg, cathedral-2.jpg …   ← фото общие для всех языков
```

Разделы сайта: `sights` (достопримечательности), `beaches` (пляжи), `food` (еда и кофе),
`catalonia` (Каталония), `plan` (советы).

Адреса страниц: `/ru/sights/cathedral/`, `/uk/sights/cathedral/`, `/en/…`, `/es/…`.
Переключатель языка на каждой странице ведёт на ту же самую страницу на другом языке.

## Как добавить новый пост (самый простой способ)

Откройте сессию Claude Code с этим репозиторием и напишите, например:

> Новый пост в раздел «Каталония»: Монтсеррат. Вот текст: …  (фото прикладываю)

Пишите на русском или украинском — Claude создаст папку, ваш текст и три перевода,
и отправит изменения. Правила для Claude записаны в `CLAUDE.md`.

## Пометка «перевод не вычитан»

Переводы помечены `reviewed: false` — на странице внизу видна маленькая заметка.
Когда носитель языка проверит текст, поменяйте на `reviewed: true` (или попросите Claude).

## Полезные вставки в тексте

- `{{< map "ID места" >}}` — ссылка «Google Карты» внутри предложения
- `{{< place "ID места" >}}` — строка «📍 Открыть в Google Картах»
- `{{< tip >}}💡 Совет…{{< /tip >}}` — выделенный блок-совет
- галерея фото:
  ```
  {{< gallery >}}
  photo-1.jpg | Подпись к фото
  photo-2.jpg | Ещё подпись
  {{< /gallery >}}
  ```

## Для разработки

```
npm install
npm run dev     # локальный просмотр на http://localhost:1313
npm run build   # сборка в папку public/
```

Публикация: при каждом изменении в ветке `main` GitHub Actions собирает сайт и выкладывает
его на GitHub Pages (`.github/workflows/pages.yml`). Для этого один раз нужно включить
Settings → Pages → Source: **GitHub Actions**. Для Cloudflare Workers есть `wrangler.jsonc`. Старая одностраничная версия сохранена в `_legacy/index.html`.
